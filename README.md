# PDF1C

Проект для работы с PDF в 1С:Предприятии. Первый этап — серверные операции:
объединение PDF и сборка документа из выбранных страниц нескольких файлов.
В перспективе — предпросмотр на HTML/JavaScript и поддержка веб-клиента.

Сейчас подготовлена пустая конфигурация `PDF1C`. Операции с PDF ещё не реализованы.

## Структура

```text
src/
  cf/           XML-выгрузка основной конфигурации
  cfe/          Место для будущей версии в виде расширения
test/           Место для будущих тестов
.local/         Локальная база и журналы; исключены из Git
```

В пустых каталогах `src/cfe` и `test` оставлены `.gitkeep`, чтобы Git сохранял структуру.
XML-исходники в `src/cf` хранятся в Git. Бинарные `*.cf`, `*.cfe`, `*.dt` и файлы
информационных баз исключены через `.gitignore`.

## База разработки

- Тип: файловая информационная база.
- Конфигурация: `PDF1C`, управляемое приложение, русский язык.
- Платформа создания: **1С:Предприятие 8.3.27.1989 (x64)**.
- Режим совместимости: **8.3.27**.
- Каталог: `E:\Workspace\pdf1c\.local\infobase`.
- Файл базы: `E:\Workspace\pdf1c\.local\infobase\1Cv8.1CD`.
- Строка соединения: `File="E:\Workspace\pdf1c\.local\infobase";`.
- Пользователи и пароли не создавались.

Для открытия в конфигураторе из PowerShell:

```powershell
& 'C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe' DESIGNER /F 'E:\Workspace\pdf1c\.local\infobase'
```

Базу можно добавить в список запуска 1С вручную: «Добавить» → «Добавление
в список существующей информационной базы» → «На данном компьютере…» →
указать каталог базы. Рекомендуемое название: `PDF1C — разработка`.

## Обмен конфигурацией с исходниками

Перед загрузкой XML в существующую базу сохраните её резервную копию.
Команды ниже предназначены для локальной базы разработки; выполняйте их при
закрытом конфигураторе. Пути нужно изменить, если проект расположен иначе.

Загрузка исходников и обновление конфигурации базы данных:

```powershell
& 'C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe' DESIGNER /F 'E:\Workspace\pdf1c\.local\infobase' /LoadConfigFromFiles 'E:\Workspace\pdf1c\src\cf' /UpdateDBCfg /Out 'E:\Workspace\pdf1c\.local\logs\load.log'
```

Выгрузка изменений после работы в конфигураторе:

```powershell
& 'C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe' DESIGNER /F 'E:\Workspace\pdf1c\.local\infobase' /DumpConfigToFiles 'E:\Workspace\pdf1c\src\cf' /Out 'E:\Workspace\pdf1c\.local\logs\dump.log'
```

Для восстановления на другом компьютере создайте пустую файловую базу
на платформе 8.3.27, создайте каталог `.local/logs`, затем загрузите `src/cf`
и обновите конфигурацию базы данных командой выше. База `.local/infobase`
не входит в репозиторий.

Параметры пакетного режима описаны в [документации 1С](https://kb.1ci.com/1C_Enterprise_Platform/1C_Enterprise_Platform_Overview/Administration_tools/Designer_batch_mode/).
