# PDF1C

Набор серверных и клиентских методов для работы с PDF в 1С:Предприятии,
расширяющий стандартные возможности платформы. Операции с PDF выполняются
через внешнюю компоненту, интегрированную в 1С.

Цель проекта — предоставить встроенное в 1С решение для работы с PDF,
позволяющее отказаться от установки и вызова сторонних программ,
таких как ImageMagick.
